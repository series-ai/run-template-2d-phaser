# Template: Phaser 3 + StowKit

## File Structure (as-shipped)

- **src/main.ts** — Entry point. Creates Phaser.Game instance (config: scene, physics arcade, scale FIT, **WEBGL renderer**). Uses RundotGameAPI for logging.
- **src/scenes/HelloWorldScene.ts** — Default scene. Demonstrates StowKit pack loading, physics, and pointer input.
- **src/style.css** — Global styles.
- **index.html** — Mount point `#app` for Phaser; optional `#dialog-overlay` for HTML overlays (e.g. dialogs). Script entry: `/src/main.ts`.
- **assets/** — Source assets (PNG, JPG, WAV, etc.). Run `stowkit build` to compress and pack into `.stow` files output to `public/cdn-assets/`.
- **public/cdn-assets/** — Built `.stow` packs deployed to CDN. Do not add files here manually — they are generated by `stowkit build`.
- **public/stowkit/** — Decoder files (Basis Universal transcoder, Draco decoder, WASM reader). Required at runtime for `.stow` decompression.
- **vite.config.ts** — Vite + `rundotGameLibrariesPlugin()`. Build target es2022 (SDK uses top-level await).
- **game.config.json** — Generated by `rundot init`. Do not edit manually.

## StowKit Asset Pipeline

1. Drop source files (PNG, JPG, WAV, etc.) into `assets/`.
2. Run `stowkit build` — compresses textures to KTX2, audio to AAC, outputs `.stow` packs to `public/cdn-assets/`.
3. At runtime, fetch `.stow` from CDN and parse with `StowKitPhaserLoader`.

## Key Patterns

- **Game loop** — Managed by Phaser. Add logic in the scene’s `update()` method.
- **Renderer** — Must use `Phaser.WEBGL` (not AUTO) for compressed texture support.
- **Input** — Use Phaser input: `this.input.on(‘pointerdown’, ...)` or `gameObject.on(‘pointerdown’, ...)`. For overlay UI, DOM is acceptable.
- **Assets (StowKit)** — Fetch `.stow` pack from CDN, parse with `StowKitPhaserLoader.loadFromMemory()`, then `pack.loadTexture(assetPath, scene)` to register textures with Phaser. Textures are keyed by their asset path. Must be called in `create()`, not `preload()`.
  ```typescript
  const blob = await RundotGameAPI.cdn.fetchAsset(‘default.stow’);
  const pack = await StowKitPhaserLoader.loadFromMemory(await blob.arrayBuffer(), {
    basisPath: ‘stowkit/basis/’,
    wasmPath: ‘stowkit/stowkit_reader.wasm’,
  });
  await pack.loadTexture(‘circle’, this);
  this.add.image(x, y, ‘circle’);
  ```
- **Audio (StowKit)** — `const audioBuffer = await pack.loadAudio(‘sfx_name’)` returns an `AudioBuffer`.
- **Spritesheets (StowKit)** — `await pack.loadSpriteSheet(assetPath, scene, animKey)` registers frames and creates an animation.
- **RundotGameAPI** — Import from `@series-inc/rundot-game-sdk/api`. Use `RundotGameAPI.log()` for debug; `RundotGameAPI.cdn.fetchAsset()` to fetch `.stow` packs from CDN.
- **Scenes** — Extend `Phaser.Scene`, pass to `scene: [MyScene]` in game config in main.ts. Use `super("scene-key")` in constructor.

## What to Modify

- **New game logic** → New scene in `src/scenes/`, add to `scene` array in main.ts config.
- **New assets** → Add source files to `assets/`, run `stowkit build`, load from pack at runtime.
- **Game config (resolution, physics)** → Phaser.Game config in main.ts.
- **Overlay UI** → Add markup in index.html, show/hide via DOM in the scene (e.g. classList add/remove).
