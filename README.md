# Phaser 3 + VenusAPI Template

Start a Venus-ready Phaser game in minutes. This repo wires up Phaser 3, TypeScript, Vite, and the VenusAPI SDK so you can focus on vibes, not setup. For more information, look up the documentation: https://series-1.gitbook.io/venus-docs

## What You Need

- Node.js 16 or newer and npm
- The [Venus CLI](https://series-1.gitbook.io/venus-docs/venus-docs/venus-cli/installing-the-venus-cli)
  - macOS/Linux: `curl -fsSL https://github.com/series-ai/venus_cli_releases/releases/latest/download/install.sh | bash`
  - Windows: `irm https://github.com/series-ai/venus_cli_releases/releases/latest/download/install.ps1 | iex`
  - Verify with `venus --help`


## Get Up and Running

```bash
npm install
npm install @series-inc/venus-sdk@latest # optional - grab the latest version of the Venus SDK
venus login
venus init --name <name> --description <description> --build-path dist
npm run dev            # opens the template at http://localhost:5173
```

When it feels ready:

```bash
npm run build
venus deploy
```

## Where Things Live

```
src/main.ts         // entry point + VenusAPI init
src/scenes/         // Phaser scenes (HelloWorld is included)
public/             // assets that ship with the app
game.config.json    // generated by venus init
```

## Venus Tips

- Use `VenusAPI.log()` for debug messages so they show up inside the Venus host.
- Need storage, ads, haptics, or CDN helpers? The GitBook’s [VenusAPI section](https://series-1.gitbook.io/venus-docs/venus-docs/venus-sdk/sdk-api-modules) walks through every API with examples.
