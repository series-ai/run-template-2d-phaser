# Phaser 3 + VenusAPI Template

A modern template for creating Phaser 3 games integrated with VenusAPI, using Vite and TypeScript.

## Features

- 🚀 **Vite** - Fast build tool and development server
- 📘 **TypeScript** - Full type safety with VenusAPI intellisense
- 🎮 **Phaser 3** - Latest version of the popular 2D game framework
- 🌟 **VenusAPI Integration** - Complete lifecycle management and platform features
- 🎨 **Modern CSS** - Beautiful styling with CSS gradients and shadows
- 📦 **Optimized Build** - Automatic code splitting for Phaser

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn
- Venus CLI: `npm install -g @series-inc/venus-cli` (see [Venus CLI docs](https://github.com/Zee-Series-AI/venus_cli_releases))

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Create your game configuration (generates `game.config.json` with unique gameId):
   ```bash
   venus create-game
   ```
   
   This will prompt you for game details and create a `game.config.json` file with a unique UUID. This file is gitignored and specific to your project.

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000`

### Build for Production

```bash
npm run build
```

**Note**: Builds with **embedded libraries by default** (Phaser loaded from Venus host). Bundle size: ~272KB vs 1.75MB bundled.

For standalone HTML5 export:
```bash
npm run build:bundled
```

### Deploy to Venus Platform

**First time setup:** Create your game configuration if you haven't already:
```bash
# Create a new game and generate game.config.json
venus create-game

# This will prompt you for game details and create:
# game.config.json (gitignored - contains your unique game ID)
```

**Deployment commands:**
```bash
# Quick build and publish
npm run yeet

# Or manually with Venus CLI
npm run build
venus update-and-publish-game
```

For more Venus CLI commands and options, see: https://github.com/Zee-Series-AI/venus_cli_releases

### Preview Production Build

```bash
npm run preview
```

## Embedded Libraries

This template uses the Venus embedded libraries system **by default**. Phaser is loaded from:
- **Mobile**: Venus host app (instant, offline-ready, 1.1MB saved)
- **Web**: CDN fallback (`venus-static-01293ak.web.app`)

**Build Scripts**:
- `npm run build` - **Default**: Embedded libraries (272KB bundle)
- `npm run build:bundled` - Standalone export (1.75MB bundle)

The Vite plugin automatically:
- Externalizes Phaser from your bundle
- Generates virtual modules that load from `window.__venusLibraryExports`
- Injects configuration for the Venus host to provide libraries
- Serves CDN assets from local `cdn/` folder during development

**When to use bundled mode:**
- Distributing standalone HTML5 games outside Venus
- Testing without the Venus host
- Creating web-only exports

## VenusAPI Integration

This template demonstrates proper VenusAPI integration with:

### Lifecycle Management
- **onShow** - Called when game becomes visible
- **onPlay** - Called when user starts playing
- **onPause/onResume** - Handle app state changes
- **onHide** - Clean up when game is hidden

### Platform Features
- **Alerts** - `VenusAPI.popups.showAlert()` for native-style dialogs
- **Logging** - `VenusAPI.log()` and `VenusAPI.error()` for proper console output
- **Storage** - `VenusAPI.appStorage` for persistent data storage across sessions
- **Haptics** - `VenusAPI.triggerHapticAsync()` for device vibration support

### Getting Started with VenusAPI

1. **Initialize First**: Always call `VenusAPI.initializeAsync()` before using any VenusAPI methods:
```typescript
const success = await VenusAPI.initializeAsync({
  helpText: "Your game description",
  mock: {} // Optional mock configuration for development
});
```

2. **Use Platform Features**:
```typescript
import VenusAPI from '@series-inc/venus-sdk/api';
import { HapticFeedbackStyle } from '@series-inc/venus-sdk';

// Logging (better than console.log for Venus platform)
VenusAPI.log('Game started');
VenusAPI.error('Something went wrong');

// Storage
await VenusAPI.appStorage.setItem('high-score', '1000');
const score = await VenusAPI.appStorage.getItem('high-score');

// Haptics
await VenusAPI.triggerHapticAsync(HapticFeedbackStyle.Medium);

// Popups
await VenusAPI.popups.showToast('Level complete!', { duration: 2000, variant: 'success' });
await VenusAPI.popups.showAlert('Game Over', 'Your score: 1000', { confirmText: 'OK' });

// See the VenusAPI documentation for full API details:
// https://www.npmjs.com/package/@series-inc/venus-sdk
```

3. **Optional Lifecycle Methods**: You can add lifecycle hooks to your scenes if needed:
```typescript
export default class MyGameScene extends Phaser.Scene {
  onShow(): void {
    VenusAPI.log('Game shown');
  }

  onPause(): void {
    VenusAPI.log('Game paused');
  }
}
```

Then register handlers in `main.ts` to connect VenusAPI events to your scene methods.

## Managing Game Assets

You have two options for static assets (images, sounds, music):

### Option 1: Bundle with App (public/ folder)
**Use for:** Small essential assets (UI elements, icons, small sprites)

```bash
# Add to public/assets/
cp sprite.png public/assets/

# Reference in Phaser
this.load.image('sprite', 'assets/sprite.png');
```

**Pros:** Fast loading, bundled with app  
**Cons:** Increases app size, deployed with every version

### Option 2: CDN Hosting (cdn/ folder)
**Use for:** Large files (background music, high-res images, videos)

#### Step 1: Understand App Name Auto-Detection
The app name is **automatically detected** from your folder path (`H5/{folder-name}/`).
- This template folder: `_template_phaser`
- CDN path prefix: `_template_phaser/`
- No manual configuration needed!

#### Step 2: Add Assets to cdn/ Folder
```bash
# Add your large assets to the cdn folder
cp background-music.mp3 cdn/assets/
cp hero-sprite.png cdn/assets/
```

#### Step 3: Reference in Code
```typescript
import VenusAPI from '@series-inc/venus-sdk/api';

// Use VenusAPI.cdn.resolveAssetUrl() with your app's folder name:
const audioUrl = VenusAPI.cdn.resolveAssetUrl('_template_phaser/assets/background-music.mp3');
this.load.audio('bgMusic', audioUrl);

// Returns different URLs based on environment:
// Local dev:  /_template_phaser/assets/background-music.mp3 (served from cdn/)
// Production: https://venus-static-cdn.web.app/_template_phaser/assets/background-music.mp3
```

#### Step 4: Local Development
The `venusLibrariesPlugin()` in `vite.config.ts` automatically serves CDN assets from your local `cdn/` folder:
- Request: `/_template_phaser/assets/background-music.mp3`
- Served from: `cdn/assets/background-music.mp3`

#### Step 5: Deploy to Production
```bash
# Option A: Local testing with Venus CLI
npm run yeet  # Installs, builds, and publishes to local Venus app

# Option B: Deploy to staging/production
npm run build
venus update-and-publish-game --env staging  # or --env production

# The venus CLI uses game.config.json to identify your game
# CDN assets are automatically synced from cdn/ folder
```

**Important Notes:**
- ✅ **DO** commit assets to `cdn/` folder
- ✅ **DO** use `VenusAPI.cdn.resolveAssetUrl()` for environment-aware URLs
- ✅ **DO** use the folder name from `H5/{folder-name}/` as your CDN prefix
- ℹ️  App name is auto-detected - no manual configuration needed

**Pros:** Doesn't bloat app, shared across versions, can update independently  
**Cons:** Network-dependent in production

### Recommended Approach
- **Small assets (<100KB)**: Use `public/assets/`
- **Large assets (>100KB)**: Use `cdn/assets/`
- **Essential loading screen**: Use `public/`
- **Background music, cutscenes**: Use `cdn/`

## VenusAPI Reference

This template uses `@series-inc/venus-sdk` version 3.1.0+. Import VenusAPI in your code:

```typescript
import VenusAPI from '@series-inc/venus-sdk/api';
import { HapticFeedbackStyle } from '@series-inc/venus-sdk';
```

### Common VenusAPI Methods

```typescript
// Initialization (already handled in src/main.ts)
await VenusAPI.initializeAsync({ helpText: 'Your game description' });

// Storage
await VenusAPI.appStorage.setItem('key', 'value');
const value = await VenusAPI.appStorage.getItem('key');

// Ads
await VenusAPI.ads.showInterstitialAd();
await VenusAPI.ads.showRewardedAdAsync();

// Popups
await VenusAPI.popups.showToast('Message', { duration: 2000, variant: 'success' });
await VenusAPI.popups.showAlert('Title', 'Message', { confirmText: 'OK' });

// Haptics
await VenusAPI.triggerHapticAsync(HapticFeedbackStyle.Light);

// Lifecycle (see VenusAPI integration examples in the template)
VenusAPI.lifecycles.onAwake(() => { /* ... */ });
VenusAPI.lifecycles.onResume(() => { /* ... */ });
VenusAPI.lifecycles.onPause(() => { /* ... */ });
VenusAPI.lifecycles.onSleep(() => { /* ... */ });

// Config and platform info
const config = VenusAPI.config;
const isMock = VenusAPI.isMock();

// Logging
VenusAPI.log('Info message');
VenusAPI.error('Error message');
```

For complete API documentation, see: https://www.npmjs.com/package/@series-inc/venus-sdk
